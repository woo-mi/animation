# Animation

A standalone copy of the Onboarding flow from https://woo-mi.github.io/owl/.

Live prototype: https://woo-mi.github.io/animation/

Source snapshot: woo-mi/owl at d276a27 (connect-your-apps/v3).

All onboarding screens, styling, transitions, and assets are copied. The canonical URL and saved appearance key are scoped to this prototype. Sidebar and skip exits stay within its bundled home/chat screens.

## Local preview

Run `python3 -m http.server 8765` in this directory, then open http://localhost:8765/.

GitHub Pages publishes the root of the main branch. No build step is needed.
